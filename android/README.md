# PU Android project moved

The native Android project now lives inside `PU-main` so the two shipping editions are separate build modules:

- `PU-main/lite` — standalone PU Lite application
- `PU-main/plus` — standalone PU Plus application
- `PU-main/shared` — shared Jetpack Compose UI and models

Use `PU-main/README.md` for the build commands and project layout. This folder is retained only as a pointer for older links.
